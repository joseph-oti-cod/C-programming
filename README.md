# 💻 Structured C Programming - Weekly Assignments & Projects

Welcome to the **Structured Programming** repository! This repository contains C programs covering core programming concepts, input/output operations, decision-making, loops, modular code design with functions, arrays, and file handling[cite: 1].

---

## 📅 Course Outline & Assignments

### 🔹 Week 1: Introduction to Basic Syntax & I/O
* **Task 1: Display Units on Offer (`units.c`)** – Displays a list of academic units for the semester in a structured format[cite: 1].
* **Task 2: User Input Processing (`user_input.c`)** – Prompts the user to enter height, bank balance (in KES), and phone number using appropriate data types (`float`, `double`, etc.) and displays formatted output[cite: 1].

### 🔹 Week 2: Mathematical Operations & Conditional Logic
* **Task 1: Geometry Calculations** – Prompts for radius and height to compute the volume ($V = \pi r^2 h$) and surface area ($SA = 2\pi r^2 + 2\pi rh$) of a cylinder[cite: 1].
* **Task 2: Bank Loan Eligibility** – Checks if a user qualifies for a loan based on age ($\ge 21$) and annual income ($\ge \text{KES } 21,000$)[cite: 1].
* **Optional Practice:** Simple and compound interest calculators using standard financial formulas[cite: 1].

### 🔹 Week 3: Decision-Making Constructs
* **Exam Eligibility:** Determines if a student qualifies for final exams based on attendance ($\ge 75\%$) and average marks ($\ge 40$)[cite: 1].
* **Water Bill Calculator:** Computes total water charges based on tiered consumption rules ($0\text{--}30$, $31\text{--}60$, and $>60$ units)[cite: 1].
* **Mobile Data Bundle Purchase:** Uses a `switch` statement to present a menu and process Internet data bundle selections[cite: 1].

### 🔹 Week 4: Iterative Loops
* **For Loop:** Prints numbers from $100$ down to $50$ in descending order[cite: 1].
* **While Loops:**
  * **ATM Withdrawal:** Simulates successive bank withdrawals using a `while` loop until the account balance reaches zero or negative[cite: 1].
  * **Number Guessing Game:** Generates a random number ($1\text{--}20$) and tracks the total attempts taken to guess it[cite: 1].
* **Do-While Loop:** Password system requiring `"1234"` to grant access[cite: 1].

### 🔹 Week 5: Modular Programming with Functions
* **`calculateElectricBill()`:** Calculates total electricity bills based on tiered unit consumption rates[cite: 1].
* **`calculateFare()`:** Calculates distance-based transport fare[cite: 1].
* **`convertToCelsius()`:** Converts temperature readings from Fahrenheit to Celsius using $C = (F - 32) \times \frac{5}{9}$[cite: 1].

### 🔹 Week 6: Arrays & Data Aggregation
* **1D Array:** Tracks 7-day daily revenues, calculating total weekly income and daily averages[cite: 1].
* **2D Array:** Models room occupancy ($5 \text{ floors} \times 10 \text{ rooms}$) for a single hotel branch[cite: 1].
* **3D Array:** Multi-branch hotel management system ($3 \text{ branches} \times 5 \text{ floors} \times 10 \text{ rooms}$) tracking vacant vs. occupied rooms[cite: 1].

### 🔹 Week 7: File I/O Operations
* **Text File Appending (`borrowed_books.txt`):** Appends library book records without overwriting past entries[cite: 1].
* **Binary File Reading (`results.dat`):** Uses C `struct`s to read binary student exam records[cite: 1].
* **Sales Analytics (`sales.txt`):** Reads daily transaction amounts line-by-line and outputs total revenue[cite: 1].
